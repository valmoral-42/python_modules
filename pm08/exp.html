2. Exercise 0 — construct.py

Purpose

This program checks whether the currently running Python interpreter belongs to a virtual environment. It prints different information and instructions depending on the result.

Imports

ImportMeaning and use
import sysGives information about the running Python interpreter: sys.prefix, sys.base_prefix, and sys.executable.
import osLets the program read environment variables such as VIRTUAL_ENV and manipulate file paths.
import siteProvides package-installation locations through site.getsitepackages() and site.getusersitepackages().

Flow

  1. Python runs main() only when the file is executed directly, because of if __name__ == "__main__".
  2. in_virtual_environment() compares sys.prefix with sys.base_prefix.
  3. If they differ, Python is running inside a venv. If they are the same, it is using global Python.
  4. get_environment_name() tries to read VIRTUAL_ENV; it extracts the final folder name with os.path.basename().
  5. get_package_path() finds the active package directory, normally a path ending in site-packages.
  6. The program prints either a success message for the venv or instructions to create and activate one.

Key commands

python3 -m venv matrix_env
source matrix_env/bin/activate      # Unix/macOS
matrix_env\Scripts\activate         # Windows
deactivate
  • python3 -m venv matrix_env creates a venv folder named matrix_env.
  • Activation changes the current terminal session so python and pip use that venv.
  • deactivate leaves the venv but does not delete it. You can activate the same venv later and keep its installed packages.

3. Exercise 1 — loading.py

Purpose

This is a Matrix population scanner. It checks packages, explains pip and Poetry, simulates 1,000 connected subjects, calculates an awakening score, places each subject into an awakening profile, counts profiles, and saves a chart as matrix_analysis.png.

Imports

ImportUse in this file
import sysUses sys.exit(1) to stop safely when dependencies are unavailable.
from importlib import metadataUses metadata.version(package_name) to ask Python which installed version a package has.
from typing import FinalMarks configuration values as constants that should not be reassigned.
import numpy as npImported inside run_analysis(). Generates numerical random data and clips values to a percentage range.
import pandas as pndImported inside run_analysis(). Creates the table, calculates columns, categorizes scores, and counts profiles.
import matplotlib.pyplot as pltImported inside run_analysis(). Saves the chart image.

Constants

ConstantRole
DEPENDENCIESMaps required package names to a plain-language purpose, so one loop can check and report them.
SUBJECT_COUNT = 1000Defines how many simulated people are generated.
PROFILE_BINSDefines numerical boundaries used to classify the awakening score.
PROFILE_LABELSDefines the ordered categories: Dormant, Questioning, Aware, Awakened.
PROFILE_COLORSDefines the colors used for the profile-count bars.

Complete flow

  1. Entry point: main() starts when loading.py runs directly.
  2. Dependency check: check_dependencies() loops over pandas, NumPy, and matplotlib.
  3. Version lookup: get_package_version() calls metadata.version(). It returns the version string or None when the distribution is missing.
  4. Graceful failure: if any required package is missing, the script prints pip and Poetry installation instructions and ends with sys.exit(1).
  5. Dependency explanation: it prints the practical distinction between pip and Poetry.
  6. Safe imports: after the checks pass, it imports matplotlib, NumPy, and pandas inside run_analysis(). The try/except ImportError is a second safety layer.
  7. Generate Matrix signal: NumPy produces 1,000 values with a normal distribution centered at 10 and a wide spread of 90. np.clip(..., 0, 100) forces all values into the valid percentage range.
  8. Generate resistance rate: NumPy produces 1,000 uniformly distributed values from 0 up to 100.
  9. Create a DataFrame: pandas stores both arrays as columns in a 1,000-row table.
  10. Calculate awakening score: the script gives Matrix signal 60
